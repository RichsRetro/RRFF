Windows originals remain unchanged. The supplied versions worked on Xbox with the manual RAM hooks; the new streaming conversion and automatic dashboard startup hooks still need a hardware check. Conversion currently supports single-file images below 4 GiB and exact recognised executable hashes. Existing image folders copy normally.

Unknown unsupported filenames are reported instead of blindly renamed. Windows sources and master backups stay unchanged.

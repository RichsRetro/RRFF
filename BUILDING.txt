RRFF v1.1.1 source

WindowsApp contains the managed formatter, Localization.cs, translations.json, all compatibility-report language resources and embedded dashboard payloads. Run build.ps1 with Windows .NET Framework build tools, then place the output in App/RRFF.App.exe.

NativeSetup contains the standalone native launcher, prerequisite checker and installer. localization.hpp uses native Windows APIs to read the system language and saved preference; the .NET check and its translated prompts do not depend on .NET. Run build.ps1 with the MinGW-w64 tools on PATH.

The matching dashboard and nxdk sources are in RRXD-Source.zip. Project and third-party terms are in Licenses. Public executable resources use neutral diagnostic build paths.

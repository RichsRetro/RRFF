RRFF source and build information

WindowsApp contains the Windows formatter sources, embedded clean Xbox payloads and project licence files. On Windows with .NET Framework build tools, run build.ps1 in that folder. The resulting managed app belongs in App/RRFF.App.exe in the release layout. Its runtime configuration targets .NET Framework 4.8.
NativeSetup contains the native prerequisite checker, portable launcher and per-user installer. Build with x86_64 MinGW-w64 g++ and windres available on PATH using build.ps1. Static runtime linking avoids a separate compiler-runtime installation on the user's PC. These native entry points have no CLR runtime header and import only Windows system DLLs.
Licenses contains separate original-project and third-party terms. kernel-patcher-source reproduces the supplied patcher's complete code/data region; see its own GPL text and build instructions.
The packaged Xbox executable resources use neutral public build paths. Executable section bytes and their load addresses match the tested binaries; the local build-directory prefix was changed only in diagnostic strings before regenerating the XBE container and its checksums.

No games, BIOSes, EEPROMs, user preferences, diagnostic logs, private device identifiers or build-machine paths are included.
